# 第08週_課堂簡化版_專題設計與驗收紀錄

## A. 任務定位
- 專題名稱：AI 課堂筆記整理器
- 目標使用者：大學生
- 使用情境：學生下課後貼上課堂筆記，快速整理成可複習的內容。
- 任務：依照原始筆記產生摘要、重點、關鍵字、複習問題與資訊缺口。
- 原文原則：只根據使用者提供的原文，不自行補造事實。

## B. 資料契約
- 技術路線：JSON Schema Structured Outputs
- strict：true
- additionalProperties：false
- 必填欄位：title、summary、key_points、keywords、review_questions、missing_information
- 型別：title/summary 為 string；其餘四項為 array of string。
- 欄位用途：讓使用者分別閱讀摘要、複習重點、搜尋關鍵字、檢查理解及發現資訊不足。

## C. 操作與呈現
- 輸入：課程名稱、原始課堂筆記
- 送出：整理我的筆記
- API 開關：預設關閉；使用者明確開啟才請求
- 長度限制：6000 字元
- 結果：依欄位標籤呈現
- 錯誤：獨立顯示，不把錯誤當成成功結果
